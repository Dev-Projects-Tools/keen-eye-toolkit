# Image Intelligence Hub

Create a modern, user-friendly website featuring two advanced photo tools, with a focus on a sleek UI and engaging animations. The website should include the following components:

AI Photo Analyzer Tool

Users can upload a folder of images.

The tool will process all images within the folder and generate a VERY LONG, detailed description of each image, highlighting all visible elements, contexts, objects, colors, and possible interpretations.

After analysis, users can enter any search query into a search bar, and the tool will intelligently find and display the image(s) that best match the description or keywords.

Photos OSINT Tool

An Open-Source Intelligence (OSINT) tool that allows users to perform in-depth investigations related to images or profiles.

Capabilities include searching for images across the web, extracting metadata, identifying locations or objects, and providing related information.

Designed for both casual browsing and serious investigative work.

Additional Feature (optional)

A Photo Editor tool allowing basic editing features like cropping, filters, or annotations, to enhance user engagement and functionality.

UI & Animations

Incorporate REALLY GOOD UI design principles with smooth transitions, interactive elements, and responsive layout.

Include engaging animations for loading, button hover effects, transitions between tools, and other interactions, enhancing user experience without explicitly defining how they should look.
